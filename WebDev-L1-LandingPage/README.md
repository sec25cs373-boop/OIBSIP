# StudyFlow — Landing Page

A responsive student productivity landing page created as part of the Oasis Infobyte Web Development Internship.

## Task

**Track:** Web Development
**Level:** Level 1
**Task:** Task 1 — Landing Page

## About the Project

StudyFlow is a simple student productivity platform concept designed to help students organize their notes, plan study sessions, and track their progress in one place.

## Features

* Sticky navigation bar
* Responsive hero section
* Call-to-action button
* Smart Notes feature
* Study Planner feature
* Progress Tracking feature
* About section
* Contact and social links 
* Responsive design for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Google Fonts (Poppins)

1. Download or clone the project.
2. Open the `WebDev-L1-LandingPage` folder.
3. Open `index.html` in a web browser.
